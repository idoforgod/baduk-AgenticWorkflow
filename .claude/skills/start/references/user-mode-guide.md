# 사용자 모드 안내

워크플로우 실행 방식을 선택해 주세요.

---

## 1. 자동 모드 (Autopilot)

AI가 워크플로우를 자동으로 진행합니다. 중요한 결정점(Go/No-Go 게이트)에서만 사용자 확인을 요청합니다.

- 빠른 진행 속도
- 품질 게이트(pACS)를 통과하면 자동 승인
- 최소한의 개입으로 결과물 완성
- 적합: 프로세스를 신뢰하고, 결과물을 빠르게 받고 싶을 때

## 2. 대화 모드 (Interactive)

매 단계마다 AI가 중간 결과를 공유하고, 사용자의 피드백을 받아 다음 단계로 진행합니다.

- 단계별 확인 및 방향 조정 가능
- 사용자의 의도를 세밀하게 반영
- 중간 산출물에 대한 실시간 피드백
- 적합: 결과물의 방향을 직접 조율하고 싶을 때

## 3. 가이드 모드 (Guided)

AI가 각 단계를 설명하면서 진행합니다. 사용자가 학습하면서 워크플로우를 이해할 수 있습니다.

- 각 단계의 목적과 방법론을 상세히 설명
- "왜 이 단계가 필요한가"를 함께 안내
- 워크플로우 구조를 이해하며 진행
- 적합: 처음 사용하거나, 프로세스를 이해하고 싶을 때
