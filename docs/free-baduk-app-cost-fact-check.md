### 1.2 한국 개인의 서비스 가입 가능 여부

#### Hetzner Cloud

| 항목 | 검증 결과 | 상세 |
|------|:---:|------|
| 한국 개인 신용카드로 가입 가능? | **조건부 확인 (위험 있음)** | Hetzner는 VISA, Mastercard, AMEX, UnionPay를 지원하며 공식적으로 국가 제한 목록을 공개하지 않는다. 그러나 **Hetzner의 자동 사기 탐지 시스템이 특정 국가 IP/결제 정보를 근거로 가입을 거부하는 사례가 다수 보고되어 있다.** 한국 사용자의 구체적 거부 사례는 확인되지 않았으나, 아시아 지역 일반적으로 거부율이 높다는 포럼 보고가 있다. |

**위험 완화 방법:**
- 여권(영문) 스캔을 사전 준비
- 자체 도메인 이메일 사용 (gmail.com 등 무료 메일 거부 사례 존재)
- VPN 미사용 (VPN 사용 시 즉시 거부)
- 거부 시 Hetzner 지원팀에 직접 문의하면 수동 승인 가능한 사례 있음

> **판정: 조건부 확인.** 기술적으로 가능하나 자동 거부 위험이 있다. **대안으로 DigitalOcean 또는 Vultr를 백업 플랜으로 준비할 것을 권고.**

## <a id="3-claude-api-simulation"></a>3. Claude API 무료 서비스 비용 추정

### 3.1 전제 조건

**모델 가격 (2026-03, Anthropic 공식)**:

| 모델 | Input / MTok | Output / MTok | Cache Hit / MTok | Batch Input / MTok |
|------|:---:|:---:|:---:|:---:|
| Claude Haiku 4.5 | $1.00 | $5.00 | $0.10 | $0.50 |
| Claude Sonnet 4.6 | $3.00 | $15.00 | $0.30 | $1.50 |

**바둑 해설 요청 가정**:
- 1회 해설 요청: ~2,000 input tokens (보드 상태 + 시스템 프롬프트) + ~500 output tokens (해설 텍스트)
- 시스템 프롬프트 캐싱 히트율: 80% (동일 프롬프트 재사용)
- 모델 배분: Haiku 80% / Sonnet 15% / 템플릿 폴백 5%
- 활성 사용자 중 해설 요청: MAU의 30%가 월 평균 10회 요청

### 3.2 MAU별 비용 시뮬레이션

**월간 해설 요청 수 = MAU x 0.30 x 10 요청**

| MAU | 월 요청 수 | Haiku 비용 | Sonnet 비용 | 캐싱 절감 후 | **예상 월 비용** |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 1,000 | 3,000 | $4.20 | $3.15 | ~60% 절감 | **$3-5** |
| 5,000 | 15,000 | $21.00 | $15.75 | ~60% 절감 | **$15-25** |
| 8,000 | 24,000 | $33.60 | $25.20 | ~60% 절감 | **$24-40** |
| 10,000 | 30,000 | $42.00 | $31.50 | ~60% 절감 | **$30-50** |
| 25,000 | 75,000 | $105.00 | $78.75 | ~60% 절감 | **$75-125** |
| 50,000 | 150,000 | $210.00 | $157.50 | ~60% 절감 | **$150-245** |

**산출 근거**:
- Haiku 1회: (2,000 x $1.00 + 500 x $5.00) / 1,000,000 = $0.0045 (캐싱 전)
- Sonnet 1회: (2,000 x $3.00 + 500 x $15.00) / 1,000,000 = $0.0135 (캐싱 전)
- 가중 평균 1회: $0.0045 x 0.80 + $0.0135 x 0.15 + $0 x 0.05 = $0.00563
- 캐싱 적용: 입력 토큰의 80%가 캐시 히트 시 → 유효 비용 ~40-60% 절감
- Batch API 적용 가능 (사후 복기 등): 추가 50% 절감 가능

### 3.3 문서 수치와의 비교

| 항목 | 문서 수치 | 시뮬레이션 (MAU 8K) | 판정 |
|------|----------|---------|:---:|
| Claude API (일반 AI) | $43-65/mo | ~$10-20 (일반 AI는 해설보다 적은 토큰) | ⚠ 과대 추정 가능 |
| LLM 바둑 해설 | $115-180/mo | ~$24-40 | ⚠ **대폭 과대 추정** |
| 합계 | $158-245/mo | **$34-60/mo** | ⚠ 수정 필요 |

> **분석**: 문서의 LLM 비용 추정($158-245/mo at MAU 8K)은 **프롬프트 캐싱과 Batch API 할인을 과소 반영했거나, 요청 빈도를 과대 추정한 것으로 보인다.** 현실적 시뮬레이션에서는 MAU 8K 기준 $34-60/mo가 더 합리적이다. 단, 이는 "MAU의 30%가 월 10회 해설 요청"이라는 보수적 가정에 기반하므로, 실제 사용 패턴에 따라 변동한다.
>
> 문서의 수치가 "캐싱 없이 모든 요청이 신규"를 전제했다면 $115-180 범위가 설명될 수 있다. **캐싱은 반드시 적용해야 하는 최적화이므로, 캐싱 후 비용을 기준으로 삼는 것이 정확하다.**

### 3.4 비용 곡선 특성

| 특성 | 분석 |
|------|------|
| **선형 vs 비선형** | **거의 선형**. LLM API 비용은 토큰 소비에 비례하고, 토큰 소비는 요청 수에 비례. MAU와 요청 수가 선형 관계이면 비용도 선형. 단, PostHog의 단계별 요금 감소(step-down pricing)처럼 대량 할인이 있으면 약간 비선형(유리한 방향)이 될 수 있다. |
| **비선형 요소** | 캐싱 히트율은 사용자 수 증가 시 오히려 개선(동일 프롬프트 재사용 빈도 증가) → 단위당 비용이 약간 감소하는 **규모의 경제** 효과. |
| **위험 구간** | MAU 50K 이상에서 월 $150-245 수준. **무료 서비스에서 이 비용을 순수 지출로 감당해야 한다.** |

### 3.5 무료 서비스에서 LLM 비용 제어 방법

| 방법 | 절감 효과 | 구현 난이도 | 상세 |
|------|:---:|:---:|------|
| **프롬프트 캐싱** | 90% (캐시 히트) | 낮음 | 시스템 프롬프트 + 고정 보드 상태 부분을 캐싱. `cache_control` 설정만 추가 |
| **Batch API** | 50% | 중간 | 사후 복기, 비실시간 분석에 적합. 24시간 내 비동기 처리 |
| **템플릿 우선 (Phase 1)** | 100% | 높음 | 패턴 매칭 기반 해설은 API 호출 $0. 커버리지 80%+ 목표 |
| **Rate Limiting** | 가변 | 낮음 | 사용자당 일일/월간 해설 요청 상한 설정 (예: 무료 사용자 일 5회) |
| **모델 라우팅** | 30-50% | 중간 | 간단한 질문 → Haiku, 복잡한 분석 → Sonnet. 질문 분류기 필요 |
| **시맨틱 캐싱** | 30-50% | 높음 | 유사 질문에 대해 이전 응답 반환. 벡터 임베딩 + 유사도 검색 필요 |
| **하드캡 (월 예산 상한)** | 안전망 | 낮음 | 월 $X 초과 시 템플릿으로 자동 폴백 |

> **권장 조합**: 템플릿 우선 + 프롬프트 캐싱 + Rate Limiting + 하드캡. 이 4가지만으로 LLM 비용을 MAU 8K 기준 **$20-40/mo** 수준으로 제어 가능.

### 무료 서비스 전환의 핵심 재무 영향

```
수정 전 (Freemium):
  Phase 1 운영비: $66/mo → Phase 2: $519-606/mo (Stripe 포함)
  MRR 수입:       $5,000+ (Phase 2)
  순수익:         $4,400+/mo

수정 후 (완전 무료):
  Phase 1 운영비: $62/mo → Phase 2: $96-122/mo (캐싱 최적화 적용)
  MRR 수입:       $0
  순손실:         -$96 ~ -$122/mo (Phase 2)
```

> **결론**: 완전 무료 서비스로 전환하면 Stripe 수수료($295/mo+)가 제거되어 운영비가 크게 줄지만, **수입이 $0이 되므로 지속가능성은 전적으로 외부 자금(기부, 후원, 개인 부담)에 의존**한다. Phase 1 기준 월 $62, Phase 2 기준 월 $96-122는 개인이 취미 프로젝트로 부담할 수 있는 수준이나, **MAU 증가에 따른 LLM 비용 증가(선형적)가 주요 위험**이다.
